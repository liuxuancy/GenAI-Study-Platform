User accounts

Every account on the platform, across all three roles. Two things can be changed here: what an account may do, and whether it may sign in.

Account ID Role Last sign-in Status Actions

A freeze takes effect on the next sign-in attempt; a role change on the next successful one.

Freezing stops sign-in and nothing else — the account’s courses, answers and messages are kept, and a restore returns the person exactly where they left off. Resetting a password sets a temporary one you have to pass on yourself: this prototype has no mail service, so the new password is never sent anywhere.
